# Task Manager CLI

A simple command-line task manager built with Node.js.

## Features

- ✓ Add tasks
- ✓ List all tasks
- ✓ Mark tasks as completed
- ✓ Delete tasks
- ✓ Persistent storage

## Installation

```bash
npm install -g task-manager-cli
```

## Usage

```bash
# Add a new task
task-manager add "Buy groceries"

# List all tasks
task-manager list

# Mark task as done
task-manager done 1

# Delete a task
task-manager delete 1

# Show help
task-manager
```
